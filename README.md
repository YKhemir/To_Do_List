# 📝 To-Do List

Une application web simple pour gérer ses tâches quotidiennes, développée en HTML, CSS et JavaScript vanilla.

## 🚀 Fonctionnalités

- Ajouter une tâche via le champ de saisie
- Valider avec le bouton ou la touche Entrée
- Cocher une tâche pour la marquer comme faite
- Validation : impossible d'ajouter une tâche vide

## 🛠️ Technologies utilisées

- HTML5
- CSS3
- JavaScript (vanilla, sans framework)

## 📦 Installation

1. Cloner le repository :
```bash
git clone https://github.com/YKhemir/To_Do_List.git
```

2. Ouvrir `index.html` dans un navigateur

Aucune dépendance externe requise.
